# 轻颜相机 · 光，不止一面

黑银色沉浸式 3D 单页网页：悬浮手机、螺旋画廊、快门飞片与品牌星环。

GitHub Pages 地址：https://clararui.github.io/qingyan-light-space/

本仓库提供可直接发布的静态文件，依赖与素材全部本地化。Pages 使用 main 分支的根目录发布；提交更新后自动重新部署。

本地预览：在仓库目录运行 `python3 -m http.server 4173`，访问 http://127.0.0.1:4173/ 。请通过 HTTP 打开。

原始完整工程、构建脚本和素材配置见 [qingyan-camera-source.zip](./qingyan-camera-source.zip)。原创代码遵循 MIT，第三方库和摄影分别遵循其原有许可。
